# 🍲 HomeFeast — Homemade Food & Tiffin Service Platform

HomeFeast is a responsive web platform designed to connect people with local home cooks and tiffin providers. It aims to make fresh, hygienic, and affordable homemade meals easier to discover.

## 🌟 Features

* **Explore Meals:** Browse homemade meal options and view their details.
* **Search & Filter:** Find meals based on available search criteria and filters.
* **Meal Details:** View meal descriptions, cuisine, cook information, ratings, locations, and prices.
* **Customer Dashboard:** Access customer-related information and available features.
* **Cook Dashboard:** View cook-related information and service management options.
* **Admin Dashboard:** Provide an administrative interface for managing platform information.
* **Meal Plans:** Display meal plans designed for regular homemade food services.
* **Responsive Design:** Adapt the interface to different screen sizes.
* **Interactive UI:** Provide a smooth and user-friendly browsing experience.

*Note: Feature availability depends on the current implementation. Some functionality may use demo data.*

## 🎯 Problem Statement

Students, working professionals, and people living away from home may struggle to find affordable, hygienic, homemade meals regularly. Traditional food delivery platforms primarily focus on restaurants and may not adequately support local home cooks or recurring tiffin services.

HomeFeast aims to provide a convenient platform for discovering homemade meals and exploring regular meal options.

## 🎯 Project Objectives

* Make homemade meal options easier to discover.
* Connect customers with local home cooks and tiffin providers.
* Display meal details and pricing clearly.
* Provide interfaces for customers, cooks, and administrators.
* Demonstrate a convenient meal-plan browsing experience.
* Create a responsive and user-friendly website.

## 🚀 Installation and Setup

### Prerequisites

Install Node.js and npm before running the project.

### 1. Clone the repository

```bash
git clone https://github.com/tisha-soni23/HomeFeast.git
```


### 2. Navigate to the project directory

```bash
cd homefeast
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build the project

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```

## ⚙️ Project Workflow

1. Users visit the HomeFeast website.
2. They explore available homemade meal listings.
3. They use the available search and filtering options.
4. They review meal information and available plans.
5. Customer, cook, and admin dashboards demonstrate different platform interfaces.

Actual booking, authentication, payment, and order-processing capabilities depend on the backend functionality but not implemented in the project.

## 🔐 Limitations

HomeFeast is a web development project and may use sample data or demonstration interactions.

Features requiring a production backend, including secure authentication, database persistence, live order processing, and payment integration, require appropriate backend services if they are not already implemented.

Do not use demonstration forms to submit real passwords or payment details.
